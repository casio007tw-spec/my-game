# 經典 2048 益智遊戲 - 期中專題作品

本專題為經典數字合併益智遊戲 **2048** 的完整實作，採用原生前端技術（HTML5 + CSS3 + JavaScript ES6）開發。專注於**二維陣列（矩陣）演算法**、**遊戲狀態機**與**平滑流暢的使用者互動介面**。

---

## 🎮 專案特色與功能

1. **核心矩陣滑動與合併**：
   - 支援上下左右四方向滑動合併相同數字（$2 + 2 = 4$、$4 + 4 = 8$ ... 直至 $2048$）。
   - 每次有效移動後，於空白位置隨機生成數值為 `2`（90% 機率）或 `4`（10% 機率）的新方塊。
2. **即時計分與歷史最高分紀錄**：
   - 即時累加每次合併獲得的分數，並附帶浮動向上飄移動畫特效。
   - 整合瀏覽器 `localStorage`，重新整理或關閉分頁後仍能保留玩家的最佳紀錄。
3. **悔棋復原功能 (Undo)**：
   - 具備上一步狀態快照機制，失誤時可隨時按下「復原」按鈕回到上一步。
4. **勝負狀態判斷**：
   - **獲勝條件 (Win)**：首次合成出數值 `2048` 方塊時跳出勝利結算視窗，並提供「繼續挑戰」按鈕供玩家衝刺更高分。
   - **失敗條件 (Game Over)**：當 16 格全部填滿且相鄰四向皆無相同數字可合併時，精準判定遊戲結束。
5. **跨平台多裝置支援**：
   - 支援鍵盤 **方向鍵** 與 **WASD** 鍵操作。
   - 支援行動裝置／平板螢幕的 **Touch 滑動手勢**（Swipe）。
   - 採用響應式設計 (RWD)，不同螢幕尺寸下皆能自動縮放適配。

## 🧠 核心演算法亮點剖析

在 2048 遊戲中，處理「四個方向」的方塊移動若各自撰寫邏輯，容易導致程式碼重複且容易產生邊界錯誤。本專題採用**數學矩陣變換**將四方向統一降維處理：

### 1. 單列滑動與合併演算法 (`slideAndMergeRow`)
針對一維陣列進行向左壓縮與雙雙合併：
```javascript
// 範例輸入：[2, 0, 2, 4]
// 步驟 1 (壓縮去除 0)：[2, 2, 4]
// 步驟 2 (雙雙比對合併)：第一個 2 與第二個 2 相同 -> 合併為 4，分數 +4
// 步驟 3 (補齊 0 至 4 格)：[4, 4, 0, 0]
```

### 2. 矩陣轉置與鏡像翻轉變換 (Matrix Transformation)
透過兩種基本的二維矩陣數學操作，將向右、向上、向下的運算全部轉換為「向左滑動」：
* **向左 (Left)**：直接針對每一列執行 `slideAndMergeRow`。
* **向右 (Right)**：每一列水平鏡像反轉 $\to$ 向左滑動 $\to$ 再次反轉復原。
* **向上 (Up)**：矩陣轉置（行列對調） $\to$ 向左滑動 $\to$ 矩陣轉置復原。
* **向下 (Down)**：矩陣轉置後翻轉 $\to$ 向左滑動 $\to$ 翻轉後轉置復原。

> **優勢**：演算法核心維持單一邏輯（Single Source of Truth），大幅提升可維護性與正確性。

### 3. Game Over 遊戲結束判定邏輯
演算法依序檢查兩大條件：
1. **空間檢查**：檢查 $4 \times 4$ 陣列中是否存在值為 `0` 的空白格；若有，代表仍可移動。
2. **相鄰可合併性檢查**：若無任何空格，遍歷每個方塊檢查其**水平相鄰**（$board[r][c] == board[r][c+1]$）或**垂直相鄰**（$board[r][c] == board[r+1][c]$）是否有相同數值。
3. 若上述兩條件皆不符合，則確定盤面已完全死鎖，觸發 Game Over。
